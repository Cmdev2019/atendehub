# 37-Templates — Templates

## Objetivo

Guardar modelos reutilizáveis de documento.

## Responsabilidade

Reduzir atrito e padronizar formato. Documento novo começa de um template, não de uma página em branco.

## Conteúdo esperado

- Template de ADR
- Template de post-mortem
- Template de RFC e de proposta técnica
- Template de plano e caso de teste
- Template de ata de reunião
- Templates de issue e pull request

## Quem utiliza

Todo o time.

## Quando utilizar

Ao criar documento novo do tipo correspondente.

## Quem pode alterar

Tech lead e responsáveis pelos processos.

## Estado atual

Templates de issue e PR ficam em `.github/`, por exigência do GitHub, e são referenciados aqui.
