# 07-Frontend — Frontend

## Objetivo

Documentar a aplicação React: estrutura, padrões de componente, estado e estilo.

## Responsabilidade

Ser o guia de quem escreve código no front. Inclui o design system e as diretrizes visuais.

## Conteúdo esperado

- Estrutura de pastas e organização por feature
- Convenções de componente, hook, contexto e serviço
- Padrão de estado (local, global, servidor) e quando usar cada um
- Design system: tokens, componentes primitivos, acessibilidade
- Diretrizes de logo, ícones e identidade visual
- Guia de criação de uma tela nova

## Quem utiliza

Desenvolvedores frontend, designers.

## Quando utilizar

Ao criar tela ou componente; ao revisar PR de front; no onboarding.

## Quem pode alterar

Time de frontend, com revisão do tech lead. Diretrizes visuais exigem aval de design.
