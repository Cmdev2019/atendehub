# 32-Releases — Releases

## Objetivo

Guardar o histórico de versões liberadas e as notas de cada uma.

## Responsabilidade

Permitir responder "o que mudou entre a versão X e a Y" sem ler o log do Git.

## Conteúdo esperado

- Notas de release por versão
- Changelog consolidado
- Ritual e calendário de release
- Evidência de validação de cada release
- Comunicação ao cliente por versão

## Quem utiliza

Todo o time, suporte, clientes.

## Quando utilizar

A cada release; ao investigar quando um comportamento mudou.

## Quem pode alterar

Gerado por automação a partir dos commits; revisado pelo tech lead antes da publicação.

## Estado atual

Ainda não há `CHANGELOG.md` versionado nem releases marcadas.
