# 39-Glossario — Glossário

## Objetivo

Definir o vocabulário do domínio — a linguagem ubíqua do projeto.

## Responsabilidade

Garantir que "conversa", "fila", "atendimento", "caixa" e "canal" signifiquem exatamente a mesma coisa no código, na documentação e na conversa com o cliente.

## Conteúdo esperado

- Termos de domínio com definição precisa
- Mapeamento termo de negócio → entidade de código
- Siglas e acrônimos
- Termos ambíguos a evitar, com a alternativa recomendada
- Equivalências com termos usados por concorrentes

## Quem utiliza

Todo o time, especialmente quem está entrando.

## Quando utilizar

No onboarding; ao nomear entidade, tabela ou tela; quando duas pessoas discordam do significado de um termo.

## Quem pode alterar

Product Management e arquitetos em conjunto. Termo novo no glossário deve refletir-se no código.

## Estado atual

Essencial para a linguagem ubíqua do DDD. O código já usa termos consistentes em português para conceitos de negócio.
