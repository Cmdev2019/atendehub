# Testes unitários

## Objetivo

Verificar unidades isoladas — função, service, componente — sem tocar em banco, rede ou fila.

## Responsabilidade

Cobrir regra de negócio e caminho de erro. Rodam em segundos e a cada commit.

## Conteúdo esperado

- Plano de teste desta natureza
- Casos de teste e massa de dados
- Evidências de execução, arquivadas por release
- Relatório consolidado com resultado e ações

## Quem utiliza

Desenvolvedores.

## Quando utilizar

Continuamente, durante o desenvolvimento.

## Quem pode alterar

QA e engenharia. Evidência de execução nunca é apagada — é arquivada por release.

## Estado atual

Cobertura atual: 302 testes no front (31 suítes) e 265 no backend (30 suítes), todos verdes.
