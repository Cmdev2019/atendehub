# Testes de performance

## Objetivo

Medir tempo de resposta e consumo sob carga nominal.

## Responsabilidade

Estabelecer e proteger a linha de base de latência por rota.

## Conteúdo esperado

- Plano de teste desta natureza
- Casos de teste e massa de dados
- Evidências de execução, arquivadas por release
- Relatório consolidado com resultado e ações

## Quem utiliza

QA, engenharia, DevOps.

## Quando utilizar

Antes de cada release; ao otimizar.

## Quem pode alterar

QA e engenharia. Evidência de execução nunca é apagada — é arquivada por release.

## Estado atual

Nenhuma linha de base estabelecida.
