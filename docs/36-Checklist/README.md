# 36-Checklist — Checklists

## Objetivo

Centralizar listas de verificação operacionais e de qualidade.

## Responsabilidade

Transformar conhecimento tácito em passo verificável. Toda etapa crítica repetida deve virar checklist aqui.

## Conteúdo esperado

- Checklist de segurança pré-produção
- Checklist de go-live
- Checklist de revisão de PR
- Checklist de onboarding de dev
- Checklist de release e de rollback
- Checklist de resposta a incidente

## Quem utiliza

Todo o time.

## Quando utilizar

Sempre que executar o procedimento correspondente.

## Quem pode alterar

Quem é dono do processo. Item de checklist só é removido com justificativa registrada.

## Estado atual

Os checklists da seção 11.5 do plano de evolução são a base inicial.
